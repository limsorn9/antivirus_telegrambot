# 📜 ច្បាប់ស្តីពីការរក្សាទុកកូដ និងទិន្នន័យចាស់ (STRICT CODE INTEGRITY & PRESERVATION RULE)

## ⚠️ គោលការណ៍រឹងមាំ និងដាច់ខាត (Strict & Unbreakable Rules):

1. 🚫 **ហាមលុបកូដចាស់ (NEVER Delete Existing Code)**:
   - ហាមលុប ឬដកចេញនូវមុខងារចាស់ៗ មុខងារសុវត្ថិភាព ឬ Logic ដែលមានស្រាប់ជាដាច់ខាត ប្រសិនបើគ្មានការបញ្ជាផ្ទាល់ពីម្ចាស់ (User)។

2. 🚫 **ហាមសង្ខេបកូដ ឬកាត់បន្ថយកូដ (NEVER Summarize or Truncate Code)**:
   - រាល់ពេលសរសេរកូដ ឬ Update កូដ ត្រូវតែសរសេរកូដពេញលេញ ១០០% (Full Complete Code) ដោយមិនត្រូវកាត់បន្ថយ ឬប្រើពាក្យសង្ខេប (ដូចជា `... rest of code ...`) ឡើយ។

3. 🗄️ **រក្សាការពារមុខងារ និងទិន្នន័យចាស់ទាំងអស់ (Preserve All Features & Data Vault)**:
   - ត្រូវរក្សាការពារនូវរាល់មុខងារទាំងអស់ដែលបានបង្កើតរួច៖
     - ប្រព័ន្ធស្កេន និងលុបមេរោគ `.apk`, `.exe`, `.scr`, `.bat`, `.jpg.apk`
     - ប្រព័ន្ធ Stealth Master Privacy (លាក់បាំងសកម្មភាព Master ក្នុង Group ១០០%)
     - ប្រព័ន្ធ 100% Button-Driven (Dashboard & Sub-menus គ្រប់ជំហាន)
     - ប្រព័ន្ធ Client CRM Vault (`clients_database.json`) & Security Audit Logs (`security_audit_logs.json`)
     - ប្រព័ន្ធ Auto-Delete សារ Alert ក្នុងរយៈពេល ៦០ វិនាទី
     - ប្រព័ន្ធ Anti-Flood Spam & Clean Group
     - ប្រព័ន្ធចែកសិទ្ធិ ២ កម្រិត (Master Owner vs Client Admin)

4. 🔒 **ត្រូវការការអនុញ្ញាតច្បាស់លាស់មុនពេលកែប្រែធំ (Explicit Consent Required)**:
   - រាល់ការផ្លាស់ប្ដូរធំៗ ឬការកែប្រែទម្រង់ទិន្នន័យ ត្រូវតែមានការបញ្ជាក់យល់ព្រមពីម្ចាស់ជាមុនសិន។
